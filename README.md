# SwingDuet — ゴルフスイング比較アプリ（MVP）

自分のスイングとお手本のスイングをフォトライブラリから読み込み、**インパクトを基準点に区間別（バックスイング / ダウンスイング / フォロー）で時間同期**して並べて比較する iOS アプリです。

## ビルド方法

- Xcode 16 以降 / iOS 17 以降
- `SwingDuet.xcodeproj` を開き、Signing & Capabilities で自分のチームを設定して実機にインストールしてください
  （フォトライブラリの動画・Vision の姿勢推定を使うため、実機での動作を推奨します）

## 機能（MVP要件との対応）

### 入力
- フォトライブラリから2本読み込み（自分 / お手本）— `PhotosPicker`
- 240fps スロー動画対応 — ピッカーからは高フレームレートの元ファイルが渡され、コマ送りは実フレームレート単位
- 左右反転 — 各ペインのミラーボタン（レフティ・撮影側の違いを吸収）
- 拡大・位置合わせ — ピンチで拡大、ドラッグで移動（設定はプロジェクトに保存）

### 自動検出
- Vision（`VNDetectHumanBodyPoseRequest`）で手首座標を追跡し、手首速度からスイング区間を自動カット
- フェーズ検出（4点）
  - アドレス：動き出し前の静止
  - トップ：切り返し（手首速度が最小になる点）
  - インパクト：手首速度が最大になる点
  - フィニッシュ：インパクト後の静止
- 検出結果の手動修正 — 「フェーズ調整」画面でマーカーをドラッグ、±1コマ / ±10コマの微調整ボタン付き
- 検出信頼度が低い場合は比較画面に警告を表示

### 同期
- 基準点はインパクト固定（アドレス / トップ / インパクト / フィニッシュの4点が常に一致）
- 区間ごとに速度倍率を算出（バックスイングとダウンスイングで別々の倍率）
- 基準の切り替え（自分基準 / お手本基準）— セグメンテッドコントロール

### 再生UI
- 共通の1本のシークバーで2本を同時操作
- シークバーは区間ごとに色分け（バックスイング=青 / ダウンスイング=橙 / フォロー=緑）＋凡例
- テンポ比（例：3.0 : 1）を両者分表示
- フェーズへのジャンプ（アドレス / トップ / インパクト / フィニッシュ）
- 再生速度 0.1〜1.0倍
- コマ送り（基準側動画の1フレーム単位）
- ループ再生・区間ループ（ダウンスイングのみ等）／ループオフ

### 保存
- 比較ペアをプロジェクトとして保存・再開（動画はアプリの Documents/Videos に取り込み、設定は JSON で永続化）

### 同期の仕組み

共通タイムラインの長さは基準側のスイング区間（アドレス〜フィニッシュ）と同じ。トップ・インパクトの位置も基準側で決まり、非基準側は各区間を線形伸縮して写像します。再生中は `CADisplayLink` が共通時刻を進め、各プレーヤーは「再生速度 × 区間倍率」のレートで走行、区間境界でレートを切り替え、ドリフトが80msを超えたらシークで補正します。

### フェーズ検出の仕組み（実装リスク項目）

方針どおり **Vision の手首座標による先行検証**の実装です（クラブヘッド追跡は未実装）。240fps動画は約30fpsに間引いて解析します。検出手順：

1. 手首速度（両手首の平均位置、移動平均で平滑化）の系列を作る
2. 速度最大点 = インパクト
3. インパクトから遡って最初の低速領域の最小点 = トップ
4. さらに遡ってバックスイング動作の前の静止 = アドレス
5. インパクト以降で静止が続く点 = フィニッシュ

検出に失敗した場合は動画長ベースのフォールバック値を設定し、信頼度低の警告を出して手動修正へ誘導します。
