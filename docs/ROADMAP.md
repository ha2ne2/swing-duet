# ロードマップ（ROADMAP.md）

## プロジェクト全体の流れ

SwingDuet は、以下の 4 つのフェーズで進める：

1. **フェーズ 1**: MVP 実装 ✅
2. **フェーズ 2**: 動作確認（シミュレータ → 実機）🔄
3. **フェーズ 3**: 品質整備（テスト・既知の制約の解消）⬜
4. **フェーズ 4**: MVP 後の拡張 ⬜

---

## フェーズ 1：MVP 実装（完了）

**目的**: [SPEC.md](./SPEC.md) の MVP 要件を満たすアプリを作る。

| タスク     | 内容                                                        | 関連ファイル                                                  | ステータス            |
| ---------- | ----------------------------------------------------------- | ------------------------------------------------------------- | --------------------- |
| 入力       | 写真ライブラリの動画の取り込み、自動フィット、拡大・位置合わせ | `Views/Home/SwingListView.swift`、`Views/Stage/StageView.swift`、`Views/Picker/VideoPickerSheet.swift`、`Views/Stage/VideoPaneView.swift` | ✅ 完了（2026-09-06） |
| 自動検出   | Vision 姿勢推定（手首・腰・首）+ 手の高さによる 4 フェーズ決定、手動修正 | `Services/SwingAnalyzer.swift`、`Views/Stage/PhaseEditView.swift` | ✅ 完了（2026-09-06） |
| 同期       | インパクト基準・区間別倍率、基準側の切替                    | `Models/SyncEngine.swift`                                     | ✅ 完了（2026-09-06） |
| 再生 UI    | 共通シークバー、テンポ比、ジャンプ、速度、コマ送り、ループ  | `Services/PlaybackController.swift`、`Views/*`                | ✅ 完了（2026-09-06） |
| 保存       | クリップ（スイング / お手本）の保存・再開（JSON + 動画コピー） | `Services/ClipStore.swift`                                    | ✅ 完了（2026-09-06） |

## フェーズ 2：動作確認

**目的**: 実際の動画でフローと検出精度を確かめ、MVP として使える状態にする。

| タスク                     | 内容                                                                     | ステータス                                                                                       |
| -------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------ |
| シミュレータでの通し確認   | ビルド → 動画 2 本選択 → 解析 → 同期再生 → 保存 / 復元                    | ✅ 完了（2026-09-06、[research/260906_1531](./research/260906_1531-simulator-verification.md)） |
| 自動 E2E の整備            | XCUITest ハーネスで上記フローを自動操作                                  | ✅ 完了（2026-09-06、[.claude/skills/e2e-simulator](../.claude/skills/e2e-simulator/SKILL.md)） |
| 実機での検出精度確認       | 実スイング動画（`docs/data/`）で 4 フェーズの検出精度と信頼度判定を確認  | ⬜ 未着手（Vision はシミュレータで動作しないため実機のみ）                                       |
| 実機での再生同期確認       | 240fps 動画での同期・コマ送り・ドリフト補正の体感確認                    | ⬜ 未着手                                                                                        |

**フェーズ 2 の完了条件**:

- 実機で実スイング動画の 4 フェーズが妥当に検出される（外れる場合は手動修正で運用できる）
- 同期再生が破綻しない
