# 仕様書（SPEC.md）

## 1. プロジェクト概要

### 1.1 アプリ名

**SwingDuet**

### 1.2 プロジェクトの目的

自分のゴルフスイング動画と、お手本（プロ・コーチ等）のスイング動画を並べて比較するための iOS アプリ。

- 2 本の動画を単純に同時再生すると、テンポの違いで「トップ」「インパクト」の瞬間がずれて見比べにくい
- そこで **インパクトを基準点に、区間別（バックスイング / ダウンスイング / フォロー）で時間同期**し、
  アドレス / トップ / インパクト / フィニッシュの 4 点が常に一致した状態で並べて再生する
- 動画は端末内にローカル保存し、外部サーバーには送信しない

### 1.3 想定ユーザー

- 自分のスイングを iPhone で撮影して練習しているアマチュアゴルファー
- iPhone のスロー撮影（240fps）や通常撮影の動画、YouTube 等から保存したお手本動画を持っている
- 利用シーン: 練習場・自宅で、自分のスイングとお手本を見比べてフォームを確認する

## 2. 機能要件（MVP）

### 2.1 入力

- 起動画面は**ホーム**（自分のスイングの一覧。「★ お気に入り」の節と撮影日ごとの節。行には自分と相手のインパクトのサムネイル、名前か時刻、テンポ比、最後に比べたお手本）。下端の「＋ スイングを追加」で写真ライブラリから
  動画を 1 本選ぶと、そのスイングの**ステージ**（比較画面）が開く。行をタップしても同じステージが開く
- **動画を選ぶ画面**は「動画」「お手本」の 2 タブ。「動画」は写真ライブラリの動画だけを撮影日順に並べた自前のグリッド（長さとスロー撮影の印付き）で、
  セルをタップ → プレビュー（繰り返し再生。映像下端の細い進捗バーでシーク。スロー撮影は原本を等速で再生）→「この動画を使う」。「お手本」は登録済みのお手本と ★ お気に入り（★ の付いたスイング）のカードで、
  タップするとそのまま使う（再解析なし）。どちらのタブから選んでも、開いたときに押した側のペインに入る
- ステージの各ペインの右上に「替える」ボタン。左の「替える」は「動画」タブで、右の「替える」（お手本が無ければ中央の ⊕）は「お手本」タブで開く。
  右に「動画」タブの動画を入れるときは名前を付けて**登録済み**になる（名前が空なら撮影日時で表示。「今回だけ使う」なら棚には並べず、この比較にだけ使う。
  相手にしているスイングが無くなれば次回起動時に消える）。カードの「…」で名前の変更・削除（お手本）、★ から外す（お気に入り）
- 解析はステージの中で進む（左が解析中、右はいつものお手本 = 最後に比べた相手）。解析中に一覧へ戻っても続き、行に進捗が出る。
  1 本ずつ直列で解析し、途中で終了しても次回起動時に続きから
- 「動画」タブは写真ライブラリの読み取り権限を使う。許可すれば iPhone のスローモーション動画を**原本（120 / 240fps・実速）のまま**取り込める。
  限定アクセスなら許可した動画だけを出し「さらに選ぶ」で追加。拒否したときは設定への案内と、権限の要らない OS のピッカー（`PhotosPicker`。
  この経路のスローモーション動画は 30fps のレンダリング版）
- 同じ写真ライブラリの動画を選び直したときは、動画ファイルと解析結果を共有する（同じ役割で既にあればそれを開く）
- スロー再生が焼き込まれた動画（YouTube のスロー動画、他アプリの書き出し）は、動画の速さ（実速 / 1/2 / 1/4 / 1/8 / 1/16 / 1/32）を
  フェーズのダウンスイング長から推定し（§2.2）、フェーズ調整画面で選び直せる。再生速度はこの速さで戻した実速が基準になる（§2.4）。
  倍率はフェーズ調整画面で確認できる
- 240fps などの高フレームレート動画に対応する（コマ送りは実フレームレート単位）
- 自動フィット（初期表示は検出した人物が余白付きで収まるように自動で拡大する。人物を検出できなければ等倍）
- 拡大・位置合わせ（ピンチした位置を中心に 0.5〜4 倍で拡大縮小、ドラッグで移動。ペインごとに独立し、左の位置はスイングに、
  右の位置は「このスイングとこの相手」に保存されるので、一覧に戻っても再起動しても保持される）

### 2.2 自動検出

- 体に対する手の高さ（Vision の姿勢推定で追った手首・腰・首）からスイングとフェーズ 4 点を自動検出する（正面・後方どちらの撮影でも同じ仕組み）
  - アドレス：手が低い位置で動き出す直前
  - トップ：手が最も高い点の後、下ろし始めるところ（切り返し。トップで止まっても、スロー動画で間が伸びても同じ）
  - インパクト：トップの後、手が最も低くなる点
  - フィニッシュ：インパクト後、手がフィニッシュの高さに達する点
  - 手首が体の陰やブレで見えない区間に切り返しが掛かるときは、再出現とテンポの比（バックスイング : ダウンスイング = 3 : 1）で推定する
- **1 本の動画に複数のスイング（素振りなど）が写っていてよい**。アドレスごとにフェーズを求めて候補とし、
  最も振り切っているもの（振り上げの大きさとピーク速度。同程度なら後のスイング）を自動で採用する
- 複数人が写る動画（2 視点の合成など）でも同じ人物を追い続ける
- 動画の速さ（焼き込みスローの倍率）はフェーズのダウンスイング長から推定する（フェーズの純関数。手で直せば推定も追従する）。
  境目は 0.52 / 1.04 / 2.08 / 4.2 / 8.3 秒で実速寄りに丸め、検出失敗時の仮のフェーズのままなら実速扱い。
  隣の倍率とは内容から区別できないので推定は提案で、ユーザーが選んだ値があればそれが優先
- 検出結果は手動で修正できる（マーカーのドラッグ、±1 / ±10 コマの微調整、スイング候補の切り替え、動画の速さ）
- 検出信頼度が低い場合（検出失敗・手首の検出率が低い・トップかインパクトを推定で置いた）は `lowConfidence` として記録する。
  比較画面には出さず、修正は「フェーズ調整」から行う（取り込み直後に確認する案は
  [design/260907_0159](./design/260907_0159-stage-entry-points.md) の案4）

### 2.3 同期

- 基準点はインパクト固定。4 点が常に一致するよう区間ごとに速度倍率を算出する
  （バックスイングとダウンスイングは別々の倍率）
- 基準側（自分基準 / お手本基準）を切り替えられる

### 2.4 再生 UI

- ステージが比較になった時点で自動で再生が始まる（両方の動画の準備ができてから）
- 共通の 1 本のシークバーで 2 本を同時操作。区間ごとに色分け（バックスイング=青 / ダウンスイング=橙 / フォロー=緑。凡例は出さない）
- テンポ比（バックスイング : ダウンスイング = N : 1）はフェーズ調整画面とホームの行に表示する（比較画面には出さない）
- フェーズへのジャンプ（アドレス / トップ / インパクト）
- 再生速度は**実速に対する倍率** 0.1 / 0.2 / 0.3 / 0.5 / 1.0（速度表示をタップで切り替え）。焼き込みスローは基準側の速さで戻すので、
  どの動画を基準にしても x1 は実世界の速さ。左右両方がスローでも同じ
- コマ送りはジョグホイール：再生ボタンの周りの帯を回すと基準側動画の 1 フレーム単位で進む（時計回りが進む。1 周 30 コマ）。
  帯の左右のタップで ±1 コマ。回し続けると 1 周ごとに 1 目盛りのコマ数が倍になる（2 周目 2 コマ、3 周目以降 4 コマ。
  離す・止める・逆回転で 1 コマに戻る）。
  1 コマごとに軽い触覚、トップ / インパクトの通過で中くらい、ループ範囲の端で重い触覚
- ループ再生：スイング全体 / 区間のみ（ダウンスイングのみ等）/ ループしない。ループする間はシークバーのループ範囲の両端に常につまみが出て
  （既定のスイング全体では左右の端）、端を最も近いフェーズから整数コマの位置で動かせる（ドラッグ中は両方の映像がその端のコマを映す。
  動かした範囲はループのメニューに「トップ −4 コマ 〜 インパクト +6 コマ」と出る。範囲は保存しない）。
  ステージでは画面の左端からのスワイプで一覧へ戻る操作を止める（左端のつまみを右へ動かす指が戻る操作に取られるため。一覧へは左上の「<」で戻る）

### 2.5 保存

- 取り込んだ動画は**クリップ**（スイングかお手本）として自動で残る（保存ボタンは無い）。動画は映像トラックだけをアプリ内にコピーし、
  解析結果・フェーズの手直し・位置合わせ・最後に比べた相手・名前・★ を JSON で永続化する
- スイングの ★（★ お気に入り）：一覧の上の節に固定され、自動では消えない。「お手本」タブにも「★ お気に入り」として並ぶので、自分のお気に入りを相手にできる
- ★ の無いスイングは 60 本まで残り、超えた分は古い順に自動で消える（一覧のフッターに明記）
- 削除：行の「…」、「選択」でまとめて。スイングの削除は確認なしで即時、下端の「元に戻す」で 6 秒間戻せる。
  お手本の削除は確認ダイアログを出す（相手にしていたスイングは次に開くときにいつものお手本と比べる）
- 名前：行・カードの「…」から付ける。無ければ日時で表示する
- 動画ファイルはクリップ同士で共有し、どこからも使われなくなったものは次回起動時に消える

## 3. MVP で **行わない** こと

- 線引き（ガイドライン描画）
- 棒人間（姿勢オーバーレイ）
- 動画の書き出し
- YouTube 連携
- クラブヘッド追跡（手首追跡による先行検証にとどめる）

---

## 4. 非機能要件

### 4.1 互換性

- iOS 17 以降、iPhone / iPad
- Vision の姿勢推定は実機でのみ動作する（シミュレータでは検出できず、フォールバック位相になる）

### 4.2 パフォーマンス

- 240fps 動画は約 30fps に間引いて解析する
- 2 本の動画を同時に滑らかに再生する。ドリフトが 80ms を超えたらシークで補正する

### 4.3 プライバシー

- 動画・プロジェクトデータはローカル保存のみ。外部送信しない（[AGENTS.md](../AGENTS.md) §6）

## 5. データモデル

永続化は `Documents/library.json`（`Library`）と `Documents/Videos/<UUID>.<ext>`
（動画のコピー。音声トラックは取り込み時に除く。理由は [ARCHITECTURE.md](./ARCHITECTURE.md) §4）。
定義は [SwingDuet/Models/](../SwingDuet/Models/)（`Swing.swift` / `VideoConfig.swift` / `Clip.swift`）。
旧形式（`projects.json` の比較ペアと `models.json` の登録済みお手本）は初回起動時にクリップへ組み替える。

| 型                  | 内容                                                                                   |
| ------------------- | -------------------------------------------------------------------------------------- |
| `Library`           | 保存する全体。`version`（保存形式の版。古ければ起動時に組み替える）/ `clips` / `reference`（同期の基準側、既定はお手本。アプリ全体で 1 つ） |
| `Clip`              | 取り込んだ動画 1 本。`role`（`swing` = 左ペインの自分 / `model` = 右ペインのお手本）/ `name`（空なら日時）/ `createdAt` / `shotAt`（撮影日時）/ `assetID`（写真ライブラリの識別子。同じ動画の共有に使う）/ `isFavorite`（★ お気に入り）/ `isRegistered`（お手本を棚に並べるか）/ `video` / `analysis`（`pending` / `done` / `failed`）/ `pairing` |
| `Pairing`           | スイングが最後に比べた相手 `partnerID` と、そのときの右ペインの位置合わせ `scale` / `offsetX` / `offsetY`、`pairedAt`（いつものお手本の決定に使う） |
| `VideoConfig`       | 1 本の動画の設定。`fileName` / `duration` / `frameRate` / `slowFactor`（ユーザーが選んだ動画の速さ = 動画秒 ÷ 実秒。nil なら `estimatedSlowFactor` に従う。選択肢と推定は `SlowFactor`）/ `videoAspect` `focusRect`（自動フィット用の縦横比と人物の範囲） / `scale` / `offsetX` `offsetY`（自動フィットからの相対値） / `phases` / `lowConfidence` / `candidates`（検出したスイング候補）。`videoAspect` / `focusRect` / `candidates` は旧データに無くてもよい |
| `PhaseSet`          | 4 フェーズの時刻（秒）。`address < top < impact < finish` を `sanitize` / `assign` で保証。`tempoRatio` = バックスイング長 ÷ ダウンスイング長 |
| `SwingPhase`        | `address` / `top` / `impact` / `finish`                                                |
| `SwingSegment`      | `backswing` / `downswing` / `follow`（区間の色も持つ）                                 |
| `VideoSide`         | `mine` / `model`（自分 / お手本。`reference` の値にも使う）                             |
