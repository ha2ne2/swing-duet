# 仕様書（SPEC.md）

## 1. プロジェクト概要

### 1.1 アプリ名

**SwingDuet**

### 1.2 プロジェクトの目的

自分のゴルフスイング動画と、お手本（プロ・コーチ等）のスイング動画を並べて比較するための iOS アプリ。

- 2 本の動画を単純に同時再生すると、テンポの違いで「トップ」「インパクト」の瞬間がずれて見比べにくい
- そこで **インパクトを基準点に、区間別（バックスイング / ダウンスイング / フォロー）で時間同期**し、
  アドレス / トップ / インパクト / フィニッシュの 4 点が常に一致した状態で並べて再生する
- 動画は端末内にローカル保存し、外部サーバーには送信しない

### 1.3 想定ユーザー

- 自分のスイングを iPhone で撮影して練習しているアマチュアゴルファー
- iPhone のスロー撮影（240fps）や通常撮影の動画、YouTube 等から保存したお手本動画を持っている
- 利用シーン: 練習場・自宅で、自分のスイングとお手本を見比べてフォームを確認する

## 2. 機能要件（MVP）

### 2.1 入力

- 画面は比較画面（ステージ）1 枚。起動時は左右のペインが空で、ペイン中央の + から動画を選ぶ
  （ピッカー：登録済みお手本のサムネイル一覧 + 「ライブラリから選ぶ」）。右上の「お手本を選ぶ」も同じピッカー
- 右ペイン（お手本）でライブラリから選んだ動画は名前を付けて**登録済み**になり、次からはピッカーで選ぶだけで使える
  （解析結果ごと保存するので再解析しない）。左ペイン（自分）は登録しない。ピッカーのカードの長押しで名前の変更・削除
- 解析はそのペインの中で進み、もう片方はその間に選べる。両方そろうと比較になり、履歴に自動で残る
- 比較中はペインのラベルから動画を選び直せる（片方だけ入れ替えると新しい比較になる）。登録済みお手本のフェーズを修正すると登録元にも反映される
- 240fps などの高フレームレート動画に対応する（コマ送りは実フレームレート単位）
  - **既知の制約**: PhotosPicker 経由ではスローモーション動画が 30fps のレンダリング版で渡される
    （[docs/TODO.md](./TODO.md) A）
- 自動フィット（初期表示は検出した人物が余白付きで収まるように自動で拡大する。人物を検出できなければ等倍）
- 拡大・位置合わせ（ピンチした位置を中心に 0.5〜4 倍で拡大縮小、ドラッグで移動。ペインごとに独立し、設定はプロジェクトに保存されるので一覧に戻っても再起動しても保持される。リセットボタンで自動フィットに戻る）

### 2.2 自動検出

- 手首の動き（Vision の姿勢推定）からスイング区間とフェーズ 4 点を自動検出する
  - アドレス：動き出し前の静止
  - トップ：手首がアドレス位置から最も離れた点（切り返し）
  - インパクト：トップの後、手首がアドレス位置を通過する点
  - フィニッシュ：インパクト後の静止
- **1 本の動画に複数のスイング（素振りなど）が写っていてよい**。動作区間ごとにフェーズを求めて候補とし、
  最も振り切っているもの（手の移動量とピーク速度。同程度なら後のスイング）を自動で採用する
- 複数人が写る動画（2 視点の合成など）でも同じ人物を追い続ける
- 検出結果は手動で修正できる（マーカーのドラッグ、±1 / ±10 コマの微調整、スイング候補の切り替え）
- 検出信頼度が低い場合（検出失敗・手首の検出率が低い・切り返し〜インパクトがブレで未観測）は比較画面に警告を表示し、手動修正へ誘導する

### 2.3 同期

- 基準点はインパクト固定。4 点が常に一致するよう区間ごとに速度倍率を算出する
  （バックスイングとダウンスイングは別々の倍率）
- 基準側（自分基準 / お手本基準）を切り替えられる

### 2.4 再生 UI

- 共通の 1 本のシークバーで 2 本を同時操作。区間ごとに色分け（バックスイング=青 / ダウンスイング=橙 / フォロー=緑）＋凡例
- テンポ比（バックスイング : ダウンスイング = N : 1）を両者分表示
- フェーズへのジャンプ（アドレス / トップ / インパクト）
- 再生速度 0.1 / 0.2 / 0.3 / 0.5 / 1.0 倍（速度表示をタップで切り替え）
- コマ送り（基準側動画の 1 フレーム単位）
- ループ再生：スイング全体 / 区間のみ（ダウンスイングのみ等）/ ループしない

### 2.5 保存

- 両方の動画がそろった比較は自動で履歴に残る（動画はアプリ内にコピー、設定は JSON で永続化）。左上の「履歴」から開き直し・削除
- 登録済みお手本（名前・解析結果・動画）の保存。比較とは別にファイルを持つので、比較を消しても残る

## 3. MVP で **行わない** こと

- 線引き（ガイドライン描画）
- 棒人間（姿勢オーバーレイ）
- 動画の書き出し
- YouTube 連携
- クラブヘッド追跡（手首追跡による先行検証にとどめる）

---

## 4. 非機能要件

### 4.1 互換性

- iOS 17 以降、iPhone / iPad
- Vision の姿勢推定は実機でのみ動作する（シミュレータでは検出できず、フォールバック位相になる）

### 4.2 パフォーマンス

- 240fps 動画は約 30fps に間引いて解析する
- 2 本の動画を同時に滑らかに再生する。ドリフトが 80ms を超えたらシークで補正する

### 4.3 プライバシー

- 動画・プロジェクトデータはローカル保存のみ。外部送信しない（[AGENTS.md](../AGENTS.md) §6）

## 5. データモデル

永続化は `Documents/projects.json`（`ComparisonProject` の配列）と `Documents/Videos/<UUID>.<ext>`（動画のコピー）。
定義は [SwingDuet/Models/SwingModels.swift](../SwingDuet/Models/SwingModels.swift)。

| 型                  | 内容                                                                                   |
| ------------------- | -------------------------------------------------------------------------------------- |
| `ComparisonProject` | 比較ペア。`name` / `createdAt` / `mine` / `model` / `reference`（基準側、既定はお手本） |
| `VideoConfig`       | 1 本の動画の設定。`fileName` / `duration` / `frameRate` / `videoAspect` `focusRect`（自動フィット用の縦横比と人物の範囲） / `scale` / `offsetX` `offsetY`（自動フィットからの相対値） / `phases` / `lowConfidence` / `candidates`（検出したスイング候補）。`videoAspect` / `focusRect` / `candidates` は旧データに無くてもよい |
| `PhaseSet`          | 4 フェーズの時刻（秒）。`address < top < impact < finish` を `sanitize` / `assign` で保証。`tempoRatio` = バックスイング長 ÷ ダウンスイング長 |
| `SwingPhase`        | `address` / `top` / `impact` / `finish`                                                |
| `SwingSegment`      | `backswing` / `downswing` / `follow`（区間の色も持つ）                                 |
| `ReferenceSide`     | `mine` / `model`                                                                       |
