## 第 2 幕　何がどう簡単になったのか

### 2.1　区間ごとの switch が消えた

**ずんだもん**「同期の写像って、前はどうなっていたのだ？」

**めたん**「共通タイムラインの時刻を動画の時刻に直すところが、区間ごとに 3 行ずつ書いてあったの」

```swift
// 前
switch seg {
case .backswing: return p.address + frac * p.backswingDuration
case .downswing: return p.top + frac * p.downswingDuration
case .follow:    return p.impact + frac * p.followDuration
}

// 後
return p.time(of: segment.start) + fraction * p.duration(of: segment)
```

**めたん**「`SwingSegment` に『区間の始まりのフェーズ』と『終わりのフェーズ』を持たせたら、区間長も、共通タイムライン上の範囲も、
フェーズ調整画面の色帯も、全部このひとつの仕組みで書けるようになったのよ。`topBoundary` / `impactBoundary` という
2 つのプロパティも `commonTime(of: .top)` / `commonTime(of: .impact)` に吸収されたわ」

**ずんだもん**「区間が増えたら switch を 3 つ直す代わりに、`start` と `end` を 1 か所足せばいいのだ。それは分かりやすいのだ」

### 2.2　「本物そっくりの飾り」をやめて本物を出した

**ずんだもん**「比較前の画面に薄く出ている操作パネル、あれは何だったのだ？」

**めたん**「両方の動画がそろった瞬間にペインの高さが動かないように、操作パネルと同じ形の飾りを出しているの。
前はその飾りを、アイコンの名前もサイズも文字列 `"x0.30"` も含めて **38 行、手で真似して**書いていたわ。
本物の `TransportControlsView` を直したら飾りも直さないとずれる。1 年後にそれを覚えている人はいないでしょう？」

```swift
// 後：動画を持たないコントローラを渡して、本物のパネルをそのまま飾りにする
ControlPanelView(controller: .placeholder, reference: .constant(.model))
    .opacity(0.35)
    .allowsHitTesting(false)
    .accessibilityHidden(true)
```

**ずんだもん**「`placeholder` って何なのだ？」

**めたん**「`PlaybackController.placeholder`。動画を入れていないコントローラよ。これが今回の唯一の『新しい概念』で、
`PlaybackController` が 11 行増えた理由でもあるわ。なぜ存在するかは型のコメントに書いてあるから、読めば分かるはず」

### 2.3　フェーズ調整画面のシークが 7 か所から 2 か所へ

**めたん**「フェーズ調整画面では、マーカーをタップしても、ドラッグしても、±1 コマを押しても、候補を切り替えても、
プレビューをその時刻へシークするわ。前はその 5 種類の操作それぞれが最後に `seek(to:)` を呼んでいたの」

```swift
// 後：プレビューは「選択中のフェーズの時刻」を映す、と 1 か所で決める
.onChange(of: phases.time(of: selectedPhase)) { _, time in
    seek(to: time)
}
```

**ずんだもん**「操作を足すときに『シークを呼び忘れる』事故が起きなくなるのだ」

**めたん**「そう。操作側はフェーズと時刻を変えるだけ。副作用は 1 か所、というのが読みやすさの正体よ」

### 2.4　名前を実態に合わせた

**ずんだもん**「`ReferenceSide` が `VideoSide` になったのだ。どうしてなのだ？」

**めたん**「『基準側』という名前なのに、ペインの左右やプレーヤーの識別など、29 か所のほとんどが『どっちの動画か』の意味で使っていたの。
1 年後に `side: ReferenceSide` を見て『これは基準側だけ？』と立ち止まるのは無駄でしょう。
保存データの値（`mine` / `model`）は同じだから、過去の履歴もそのまま読めるわ」

**めたん**「同じ理由で、トップレベルに浮いていた `stripAudioTrack` 関数は `VideoImporter` の中へ、
同じ文言を 2 つ持っていた `SwingAnalyzerError` と `VideoImporterError` は `VideoError` ひとつにしたわ」

### 2.5　置き場所

**ずんだもん**「`Playback/` フォルダが無くなったのだ」

**めたん**「1 ファイルしか入っていないフォルダは、開いてがっかりするだけよ。`Services/` を『入出力・解析・再生制御』にして 3 層にしたわ。
調査でしか使わない関節ダンプは CLI（`scripts/analyze-swing/`）へ、ピッカーの結果型 `PickedVideo` は作る側のピッカーへ。
空だった `docs/spec/` も消したわ。仕様は `docs/SPEC.md` にあるもの」

### 2.6　コメント

**ずんだもん**「コメントは何が変わったのだ？」

**めたん**「元からよく書けていたから大きくは変えていないわ。足したのは『なぜそれで良いのか』が読み取れなかった 3 つ。
`ProjectStore` が `try?` で失敗を握りつぶす方針、`AVPlayerLayer` への強制キャストが安全な根拠、そして `placeholder` が存在する理由よ。
逆に、`assign` / `sanitize` の最小間隔は引数で受けていたけれど誰も別の値を渡していなかったから、引数をやめて本文の説明にしたわ」

## 第 4 幕　残った宿題と見送ったこと

**ずんだもん**「やらなかったことも教えてほしいのだ。1 年後のボクが『なんでこれ直ってないのだ』って言わないように」

**めたん**「3 つあるわ」

1. **比較画面の左右ペインの 2 呼び出し**（`ComparisonView.swift`）。`ForEach` にまとめるには側ごとに `Binding` を作る仕組みが要り、
   今の明示的な 2 呼び出しのほうが読みやすいと判断して据え置いた
2. **`Views/` の平置き**。13 ファイルならまだ一覧できるので分割していない。20 を超えたら Stage / Comparison / Components に分ける
3. **`PlaybackController.placeholder` は妥協**。「動画を持たないコントローラ」は少し奇妙だが、飾りを手書きで真似するよりは壊れにくい。
   もっと良い形（操作パネルがコントローラ無しで描けるなど）が見つかったら置き換える

**めたん**「それと、`xcodebuild` を回すと `project.pbxproj` のセクション順が自動で並べ替わるわ。今回は元に戻したけれど、
並べ替え後を一度コミットすれば以後は起きなくなる。これは人間の判断に委ねるわね」
