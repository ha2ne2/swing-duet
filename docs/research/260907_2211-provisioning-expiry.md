# 実機インストールしたアプリの有効期限調査（7 日で消えるか？）

## 結論

**7 日では消えない。今ビルドして実機に入れたアプリは約 1 年間（次回は 2027-09 頃まで）動く。**

チーム `TRWC68XPP9` は有料の Apple Developer Program に加入済みで、
プロビジョニングプロファイルの有効期間が **365 日** になっている。
「7 日で使えなくなる」のは無料アカウント（Personal Team、`TimeToLive: 7`）の場合のみで、本環境には該当しない。

## 確認した現状の設定

| 項目 | 値 | 確認方法 |
| --- | --- | --- |
| 署名方式 | `CODE_SIGN_STYLE = Automatic`（自動署名） | `SwingDuet.xcodeproj/project.pbxproj` |
| チーム | `DEVELOPMENT_TEAM = TRWC68XPP9`（Yuta Hashinokuchi） | 同上・プロファイル内 `TeamName` |
| Bundle ID | `com.ha2ne2.SwingDuet` | 同上 |
| 開発証明書 | `Apple Development: hayu00@gmail.com`、有効期限 2027-03-03 | `security find-identity` / `openssl x509` |
| プロファイル | `iOS Team Provisioning Profile: *`（ワイルドカード `TRWC68XPP9.*`）作成 2026-09-06、**期限 2027-09-06、TimeToLive: 365** | `~/Library/Developer/Xcode/UserData/Provisioning Profiles/` を `security cms -D` で展開 |
| 登録済みデバイス | 2 台 | プロファイル内 `ProvisionedDevices` |

アプリの起動可否を決めるのは「アプリに埋め込まれたプロファイルの期限」。
自動署名ではビルド時に必要なら新しいプロファイル（その時点から 365 日）が発行されるため、
明日ビルドすれば 2027-09 頃まで有効。証明書（2027-03 期限）が先に切れても、
インストール済みアプリは埋め込みプロファイルが有効な限り動き続ける。

## 友達の iPhone に入れるときの手順（明日やること）

自動署名のまま Xcode から直接インストールするのが最短。

1. 友達の iPhone を Mac に USB 接続し、iPhone 側で「このコンピュータを信頼」
2. iPhone の **デベロッパモードを有効化**（設定 → プライバシーとセキュリティ → デベロッパモード。iOS 16+ は必須、再起動が入る）
3. Xcode で実行先にその iPhone を選んで Run（自動署名がデバイスをチームに登録し、プロファイルを再発行する）
4. 初回起動時に「信頼されていないデベロッパ」と出たら、設定 → 一般 → VPN とデバイス管理 → デベロッパ App で信頼

有料アカウントなのでデバイス登録枠は年間 100 台・アプリ数制限なし（無料の 3 アプリ制限も無関係）。

## さらに期限を延ばしたい場合の選択肢

| 方法 | 有効期間 | 手間 |
| --- | --- | --- |
| 今のまま（開発署名で直接インストール） | ビルドから約 1 年 | 期限前に再ビルド・再インストールすれば更新される |
| TestFlight 配布 | ビルドごとに 90 日 | App Store Connect へのアップロードが必要。遠隔の相手に配るなら最適だが、期間はむしろ短い |
| App Store 公開 | 無期限 | 審査が必要。恒久的に「消えない」のはこれのみ |

明日の用途には現状のままで十分（1 年持つ）。期限が近づいたら再インストールすればよい。
