# 複数スイング・複数人物を含む動画のフェーズ検出（実データ解析）

**作成日時**: 2026-09-06 16:41 JST
**対象**: `docs/data/` の実サンプル 2 本（gitignore。お手本 = YouTube Shorts の 30fps 640×640、自分 = Golfboy の 2 視点合成 30fps 1440×1080）
**目的**: 「素振りがアドレス〜インパクトと誤認される」というユーザー報告と、自分の動画で検出が壊れる原因を実データで確認し、
検出ロジック（[ARCHITECTURE.md](../ARCHITECTURE.md) §5）の閾値の根拠を残す

---

## 1. 結論

- **お手本（YTDown）**: 素振り 2 回 + 本番 1 回が写っている。旧ロジック（速度最大 = インパクト）でも Mac 上では本番を選べていたが、
  シミュレータでは Vision が動かずフォールバック値（動画長の 15 / 45 / 55 / 85%）になり、それがちょうど素振り 1〜2 の区間に当たる。
  報告された「素振りの誤認」はこの状態を見た可能性が高い。新ロジックは 3 候補を検出し、本番（インパクト 5.87 秒）を採用する
- **自分（Golfboy）**: 正面と後方の 2 視点が左右に合成されており、同じ人物が 2 人写る。旧ロジックは `results.first` を使うため
  フレームごとに別の人物の手首を拾い、位置が左右に飛んで偽の速度（8.4。本番のピーク 2.7 の 3 倍）を末尾に出していた。
  腰の位置で同じ人物を追い続けるようにして解消。ただし 30fps ではトップ〜インパクトの 0.8 秒が完全にブレで欠測し、
  トップ・インパクトは欠測の両端になる（テンポ 0.8 : 1 と過小）。信頼度低の警告で手動修正へ誘導する

## 2. 手首速度系列の形（macOS 上の Vision、30fps に間引き、単位は正規化距離/秒）

`build/analyze-swing --series` の出力から。

### 2.1 お手本（YTDown、6.85 秒、検出率 100%）

| 区間 | 時刻 | 内容 | ピーク速度 | 手首の到達点（アドレス比） |
| --- | --- | --- | --- | --- |
| 素振り 1 | 0.5〜2.2 秒 | ハーフスイングで戻す | 0.76 | トップ距離 0.25、戻り位置はアドレスと同じ |
| 素振り 2 | 2.8〜4.3 秒 | 同上 | 0.84 | トップ距離 0.28 |
| 静止 | 4.3〜4.9 秒 | アドレス | ≤ 0.09 | |
| 本番 | 4.9〜6.3 秒 | フルスイング | **2.70**（5.87 秒 = 手首がアドレス位置を通過） | トップ距離 0.36、フィニッシュは手が高く残る（インパクトから 0.32） |
| フィニッシュ保持 | 6.3 秒〜 | ゆっくり動く | 0.1〜0.5 | |

- 切り返しの一瞬の減速: 素振りで 0.37 秒（速度 0.13 まで低下）、本番で 0.07 秒（0.38 まで）
- 素振り間の低速区間: 1.07 秒、素振り 2 〜本番: 1.07 秒

### 2.2 自分（Golfboy、4.05 秒、人物追跡後の検出率 54%）

| 時刻 | 内容 |
| --- | --- |
| 0.1〜0.5 秒 | 手首の微小な揺れ（左右手首の切り替わりによる 0.04 の飛び。3 点メディアンで除去） |
| 1.0〜1.5 秒 | バックスイング（速度 0.4〜0.9、1.59 秒に (0.53, 0.69) = アドレスから 0.34） |
| 1.6〜2.3 秒 | **欠測**（ブレ。旧ロジックではこの間に後方視点の人物 (0.12, 0.76) を拾っていた） |
| 2.4〜3.0 秒 | インパクト通過（2.56 秒、アドレスから 0.05）→ フォロー（(0.89, 0.95) まで、速度 2.7） |
| 3.0 秒〜 | 正面視点の手首は画面上端で検出不可。旧ロジックは後方視点の人物へ飛び、末尾で偽速度 8.4 |

## 3. 設計への反映

| 設計 | 根拠 |
| --- | --- |
| 動作区間の閾値 = 最大速度の 20% | 素振り（0.76〜0.84 > 0.54）を候補に含め、揺れ（≤ 0.12）を除外できる |
| 低速の連なりが 0.6 秒未満なら同じスイング | 切り返し（0.07〜0.37 秒）は結合、スイング間（1.07 秒）は分割。欠測は低速サンプルを生まないので自然につながる |
| インパクト = トップ後にアドレス位置へ最接近する点 | 本番で 5.87 秒（距離 0.02）。速度最大だと欠測時にフォロー側（Golfboy 2.94 秒）へずれる |
| トップ = アドレス位置から最も離れた点 | 速度最小より欠測に強い。Golfboy では欠測直前の 1.59 秒（真のトップは欠測内） |
| 採点 = 移動量（バックスイング + フォロー）とピーク速度、同点は後のスイング | 素振りは移動量 0.29〜0.32 / ピーク 0.3 倍、本番は 0.68 / 1.0 倍。本番と同じ振り切りの素振りなら後（本番）が選ばれる |
| 腰位置で人物追跡（1 フレーム 0.2 以内） | 合成動画で別人物へ飛ぶのを防ぐ。腰は手首よりブレに強い |
| トップ〜インパクトの欠測 ≥ 0.2 秒で信頼度低 | Golfboy の 0.81 秒欠測のように位置が推定になるケースを警告する |
