## 1. 結論

前稿の骨格（比較は自動で履歴に入り、留めたもの以外は 30 件で流れる。動画を残す手段は「お手本に登録」に寄せる）は残す。
変えるのは印と言葉、シートの出し方、削除の戻し方。起動直後の空きスペースの使い方は今回は見送りの候補。

## 2. 物差しにした作法

| 作法 | 出典 | 前稿への影響 |
| --- | --- | --- |
| 印は 1 つに 1 つの意味 | Apple Music は iOS 17.1 で「ラブ」と「ライブラリに追加」を ★ に統合。メモ・メッセージは「留める」にピン | 比較はピン、動画は ★ に分ける |
| 留めたものは上、それ以外は時系列 | メモ、メッセージ、写真 iOS 18 のピン留め、Freeform の最近 / お気に入り | 2 節構成はそのまま。名前を「ピン留め / 最近」に |
| シートは半分から、背面を触れる | マップ、`presentationDetents` + `presentationBackgroundInteraction` | 履歴を中間の高さで出し、行をタップしても閉じない |
| 確認より取り消し | メール・写真・メモ | 1 件の削除は即時。「消去」は「元に戻す」バナー |
| Liquid Glass（iOS 26） | ツールバーの丸ボタンのグループ、映像の上の操作 | 文字ボタンをガラスの丸ボタンに。iOS 17/18 は標準ボタン |

## 3. 案

| 案 | 内容 | 評価 |
| --- | --- | --- |
| A（前稿） | 履歴シートを「お気に入り / 履歴」に。比較に ★。左ペインに「☆ お手本に登録」の文字チップ。全経路で確認ダイアログ | 構造は正しいが、★ がお手本の連想と重なる。全画面シート・ダイアログ・文字チップが 1 世代前 |
| **B（推し）** | 比較は 📌 ピン留め（`pin.fill`）、動画は ★（お手本）。履歴シートは `.medium` から、行をタップすると背面のステージが切り替わる。サムネイル 2 倍（96×64、インパクト）。左ペイン右上に ★ の丸ボタン。削除は「元に戻す」。ツールバーは履歴 / 📌 / ＋ の丸ボタン | 印が iOS の慣用と一致。実装は A ＋ シートの高さ・元に戻す・ガラス |
| C（B ＋ スタートページ） | 起動直後の空ステージで、薄く描いている偽の操作パネルの場所にピン留めと最近のカード（132×88）を横に並べる | 留めた比較が起動して 1 タップ。空ステージの作り替えを伴うので B を使ってから |

## 4. 部品ごとの変更

| 部品 | 前稿 | 再考 |
| --- | --- | --- |
| 比較を留める印 | ★ お気に入り | 📌 ピン留め（systemOrange） |
| 動画を残す印 | 「お手本に登録」の文字チップ | ★。ペイン右上の 44pt 丸ボタン。長押しで名前変更・解除 |
| 節の名前 | お気に入り / 履歴 | ピン留め / 最近（シートの題とボタンは「履歴」のまま） |
| シート | 全画面 | `presentationDetents([.medium, .large])`、背面操作可、行をタップしても閉じない |
| 削除 | 全経路で確認ダイアログ | 1 件は即時。「消去」と選択削除は下端の「元に戻す」（アプリ終了まで保持） |
| サムネイル | トップ | インパクト（現行どおり）。大きさ 2 倍 |
| ツールバー | 現行 | 左：履歴。右：📌（比較中だけ）と ＋。iOS 26 は `glassEffect`、以前は標準 |
| モーション | 記述なし | `symbolEffect(.bounce)`、`contentTransition(.symbolEffect(.replace))`、`sensoryFeedback(.selection)` |

## 5. 退けた案

タブバー（舞台が 1 枚のアプリに分ける画面が無い）、履歴のグリッド化（スワイプを失う。カードは案 C の帯にだけ）、比較と動画の両方に ★、
「最近削除した項目」（30 件で流れるものに受け皿は要らない）、日数で流す（長く休むと全部消える）、起動時に前回の比較を開く（「起動時は空」は決定済み）。

## 6. 決めてほしいこと

1. 比較の印を ★ からピン留めに変えるか。推奨は変える（案 B）。「お気に入り」の言葉を残すなら案 A で、動画側は「お手本に登録」の文字にする
2. 起動直後のスタートページ（案 C）を今回入れるか。推奨は今回は B まで
3. 削除は「元に戻す」か確認ダイアログか。推奨は元に戻す
