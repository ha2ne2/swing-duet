# 同期しないで等速で流し、フェーズ 1 つで揃える

- 日付：2026-09-12
- 種別：設計 → 実装（同日）
- 対象：`Models/SyncEngine.swift`（`SyncBasis`、`SyncEngine.basis` / `anchor`）、`Models/LoopRange.swift`、`Services/PlaybackController.swift`、
  `Views/Stage/ControlPanelView.swift`、`Views/Stage/SeekBarView.swift`、`Views/Stage/TransportControlsView.swift`、`Models/Clip.swift`（`Library.syncBasis`）
- 前提：ループ範囲のつまみ（[260912_0252](./260912_0252-loop-trim-handles.md)）が入った後の操作パネル

## 1. 何を解きたいか

自分基準 / お手本基準の同期は、非基準側を区間ごとに伸縮して 4 フェーズを重ねる。形（軌道・姿勢）を見比べるには良いが、
伸縮した時点で**テンポとスイングの速さの違いは消える**。「トップからインパクトまで自分はどれだけ遅いか」「お手本のバックスイングは
どれだけゆっくりか」を見るには、伸縮せずに両方を実速で流し、どこか 1 点だけ揃えて、そこからのずれをそのまま見せる必要がある。

## 2. 決めたこと

| 項目 | 決定 | 理由・却下した案 |
| --- | --- | --- |
| 入口 | 操作パネルの基準の切り替えを 3 択に：自分基準 / お手本基準 / **同期しない** | 同期のとり方の 1 つなので同じ場所。アプリ全体で 1 つ、保存する（`Library.syncBasis`） |
| 速さ | 両方をそれぞれの速さ（`VideoConfig.effectiveSlowFactor`）で実速に戻して等速で流す。再生速度（x0.1〜x1）は両方に同じに効く | 焼き込みスローを戻さないと 1/8 の動画と実速の動画の比較にならない。区間ごとの倍率は使わない |
| 揃える点 | 同期しないに入った時点ではインパクト。アドレス / トップ / インパクトのボタンを押すと、そのフェーズで揃え直してそこへ移る（両方の映像がそのフェーズのコマになる）。揃えているボタンを塗る | 同期のインパクト基準と同じ点から見始められる。ジャンプと兼ねるので操作が増えない。揃える点は再生の設定（`PlaybackSettings`）として保存し、開き直しても戻る。同期のとり方を切り替え直したときはインパクト |
| 共通タイムライン | 早い方のアドレス〜遅い方のフィニッシュ。フェーズの位置は側ごとに違う（`commonTime(of:for:)`） | 片方のスイング区間に合わせると、もう片方のアドレスやフィニッシュが切れる |
| スイング区間の外 | 動画が続く限りそのまま流す。動画の端を越える範囲は端の絵のまま待つ（倍率 0） | フィニッシュで揃えると短いスイングの側は動画の先頭より前が要る。先頭で止めないとドリフト補正が毎 tick シークする |
| シークバー | 上下 2 本（上が自分、下がお手本。ペインの左右と同じ順）。それぞれ自分の区間の色とトップ / インパクトの線。スイング区間の外は灰色。再生ヘッドとループの枠は 2 本にまたがる | 等速で流したときのフェーズのずれが、帯の色の境目のずれとして見える。同期しているときは 1 本のまま |
| コマ送り | 細かい方の 1 フレーム（`SyncEngine.frameStep`） | 基準側が無い。どちらの動画のコマも飛ばさない |
| ループ範囲 | 区間（ダウンスイングのみ等）は両方のその区間を含む範囲。端はフェーズからのコマ数のままで、開始の端は早い方、終了の端は遅い方のフェーズから数える | 端の表現（`LoopEdge`）を変えずに済む。トップで揃えて「ダウンスイングのみ」にすると、共通のトップから遅い方のインパクトまでを繰り返せる |
| ジョグの触覚 | トップ / インパクトの通過は、どちらの側のものでも中くらいの触覚 | 同期しているときは両側同じ位置なので今までと同じ |

## 3. 写像

揃えるフェーズを P、側 s の速さを k_s（動画秒 ÷ 実秒）、フェーズの時刻を t_s(·)（動画秒）とする。

- 側 s のフェーズ q の、P からの実秒：o_s(q) = (t_s(q) − t_s(P)) / k_s
- 共通タイムラインの始まり start = min_s o_s(アドレス)、終わり end = max_s o_s(フィニッシュ)。長さは end − start
- 共通時刻 c での側 s の再生時刻：t_s(P) + (c + start) × k_s（0〜動画の長さに収める）
- 倍率：収まる範囲では k_s、外では 0

自分基準 / お手本基準の写像（区間ごとの線形伸縮）は変えていない。`SyncEngine` は `basis` で 2 つの写像を切り替える。

## 4. 見送ったこと

- 2 本のシークバーの帯に側の名前を出すこと（上が自分・下がお手本はペインの左右と同じ順）
- ループ範囲の端を側ごとに持つこと（`LoopEdge` に側を足す）。早い方 / 遅い方の規則で足りるので見送り
