# ペイン上端を「動画を替える」ボタンにする

- 日付：2026-09-11
- 種別：設計 → 実装（2026-09-11、案 B。`PaneHeader`）
- モック：https://claude.ai/code/artifact/c6f87c21-fcbf-44ca-86b9-639af6bb1ec5（同じ内容の HTML が [260911_1111-pane-swap-button.html](./260911_1111-pane-swap-button.html)）
- 対象：`Views/Stage/VideoPaneView.swift`（`PaneTitleButton`）、`Views/Stage/StageView.swift`（`SlotPane`）、`Models/Clip.swift`（`paneTitle`）
- 前提：[260907_0159](./260907_0159-stage-entry-points.md) §1 で「ラベルに見える。⌄ は 9pt」と指摘済み。今回はその上端の部品を作り直す

## 1. 問題

「自分 · 14:32 ⌄」「お手本 · マキロイ ⌄」はラベルの見た目（枠なし）で、タップで動画を選び直せることに気づけない。
下端の「フェーズ調整」は枠付きでボタンに見えるので、上端だけがラベルに見える。「自分」「お手本」の文言は、左右の並びが固定なので無くてよい。

## 2. 案

| 案 | 上端 | 名前の置き場 | 評価 |
| --- | --- | --- | --- |
| A 動詞だけ | 「⇄ 動画を替える」の枠付きボタン | ナビゲーションバーの題「14:32 · vs マキロイ」 | 最短。ペインの上で何が入っているか（倍率も）分からない |
| B 名前 ＋ ボタン | 左に名前（枠なし）、右に「替える」（枠付き） | ペインの上 | ラベルと操作が分かれる。半分の幅に 2 つで詰まる |
| **C 動詞 ＋ 名前の 2 行（推し）** | 1 つの枠付きボタン。見出し「⇄ 動画を替える」、添え字に名前・倍率 | ボタンの中 | 押せることが先に伝わり、名前も見える。部品は今と同じ 1 つ |

## 3. 案 C の詳細

- 見出し「動画を替える」（太字 11pt）＋ アイコン `arrow.triangle.2.circlepath`。添え字は名前と倍率（「マキロイ · 1/16」、10pt 薄色）。長ければ添え字だけ省略
- 角丸 12pt、枠は白 40%（「フェーズ調整」と同じ材質）。タッチ領域 44pt
- 状態：解析中・失敗でも出す（押せる）。右が空のときは出さず、中央の ⊕「お手本を選ぶ」だけ（今のまま）
- タップ先は今と同じ（左は「動画」タブ、右は「お手本」タブ）。側の説明は「動画を選ぶ」の上部の「自分（左）に入ります」が担う
- VoiceOver ラベル「動画を替える」、値に名前。E2E の識別子は `pane.mine.swap` / `pane.model.swap`

## 4. 決めてほしいこと

1. A / B / C。推奨は C（名前が要らなければ添え字を消して A に落とせる）
2. 文言。推奨は「動画を替える」。候補は「別の動画」「選び直す」
