# 履歴の見直し: お気に入りの比較と、自分の動画のお手本登録

- 日付：2026-09-10
- 種別：設計 → 実装
- 対象：`HistoryView` / `StageView` / `VideoPaneView` / `ProjectStore` / `ComparisonProject`
- 再考：[260910_0500-history-design-review.md](./260910_0500-history-design-review.md)（印・シート・削除・起動直後の見直し。実装はそちらの決定に従う）
- モック：https://claude.ai/code/artifact/3f2062ad-4116-4d04-84b1-63ba432e4c69（お気に入りと履歴の 2 節、行の操作、比較画面の ★ を描いたもの。ステージ 1 枚の現行構成より前の画面で描いているので、部品の配置は本書を正とする）

## 1. 問題

履歴（左上「履歴」のシート）が使いにくい。

| 現象                 | 原因                                                                                                                   |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 残りすぎる           | 両ペインがそろうたびに 1 件増える。比較中に片方を選び直しても、元に戻しても増える。上限が無く、消す手段は 1 件ずつのスワイプだけ |
| 消せない             | 左スワイプしか無い。編集ボタン・長押しメニュー・まとめて消す手段が無い                                                    |
| お気に入りが無い     | 比較（ペア）に星を付ける手段が無い                                                                                      |
| 動画も残したい       | 残す手段は右ペインの「お手本の登録」だけで、左ペイン（自分の動画）は登録できない                                          |

## 2. 方針

**比較は履歴に流れ、残したいものだけ ★ で留める。動画を残す手段は「お手本に登録」の 1 つに寄せる。**

- ★（お気に入り）は比較に付ける。「この組み合わせをまた見る」
- 「お手本に登録」は動画に付ける。「この動画をまた使う」。右ペインは今までどおり取り込み時に登録され、左ペイン（自分の動画）もペインのチップから登録できる。
  自分のベストスイングを登録すれば、右ペインに置いて今日のスイングと比べられる
- 動画に別の星は付けない。★ を付けた比較の 2 本は自動的に残るし、動画単体を残したいなら登録で足りる。同じ印が隣の画面で別の意味になるのを避ける

## 3. 画面と操作

### 3.1 履歴シート

- 節は「お気に入り」「履歴」の 2 つ。どちらも新しい順。お気に入りが無ければ節を出さない
- 行はこれまでどおり（両側のサムネイル・名前・お手本の名前・テンポ比 2 つ）
- 右スワイプで ★ の付け外し、左スワイプで削除。長押しメニューに「お気に入り / 名前を変更 / 削除」
- ツールバーの「選択」で複数を選び、下端の「削除」でまとめて消す
- 「履歴」の節の右に「消去」。お気に入り以外をすべて消す（確認ダイアログ付き）
- 節のフッターに「お気に入り以外は 30 件まで残ります」

### 3.2 ステージ・比較画面

- 左ペインの右上に「☆ お手本に登録」のチップ。タップで名前を付けて登録（右ペインでライブラリから選んだときと同じ名前付け）。
  登録済み（同じ動画ファイルのお手本がある）なら「★ お手本」と出て、タップで登録を外せる
- 両ペインがそろって比較を作るとき、同じ 2 本（動画ファイルの組）の比較が履歴にあれば新しく作らず、それを開いて履歴の先頭へ動かす。
  片方を選び直して元に戻したときに同じ比較が増えない

## 4. データと保存

- `ComparisonProject.isFavorite: Bool`（追加。旧データは false）。名前は今までどおり「比較 M/d HH:mm」で、履歴の長押しから変えられる
- `ProjectStore.add` のあと、お気に入り以外を新しい順に 30 件（`historyLimit`）残して残りを消す。動画ファイルはこれまでどおり起動時の参照確認で片付く
- 登録済みかどうかは動画ファイル名で判定する（`ModelVideo.config.fileName`）。左ペインからの登録は解析結果を複製して登録するだけで、比較との紐付け（`modelID`）は持たない

## 5. 検討して退けた案

| 案                                       | 退けた理由                                                                                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| 動画にも ★ を付ける                       | 動画を残す意味が「お手本に登録」と完全に重なる。印が 2 種類になって迷う                                       |
| 保存単位を動画にし、比較は保存しない       | 残したいのは「あの日の自分とあのお手本の組み合わせ」で、動画単体ではない                                       |
| ★ を押した比較だけ保存する                | 解析と手直しが保存忘れで消える。履歴も欲しい                                                                  |
| 自動削除を入れず手動だけ                   | 「残りすぎる」に戻る。上限をフッターに明記すれば驚かない                                                        |
| ペインのラベルをメニューにして登録を入れる  | ラベルのタップ（動画を選び直す）に 1 タップ増え、E2E の操作も変わる。チップを 1 つ足す方が小さい                 |
