ペイン上端を「動画を替える」ボタンにする

いまは「自分 · 14:32 ⌄」「お手本 · マキロイ ⌄」というラベルで、タップすると動画を選び直せるのに気づけない。 ラベルをやめ、動詞のボタンにする。「自分」「お手本」という言葉は出さない（左が自分、右がお手本という並びは固定なので、言わなくても分かる）。

§2 案 C の詳細

状態ごとの見え方

状態左（自分）右（お手本）
通常⇄ 動画を替える ／ 14:32⇄ 動画を替える ／ マキロイ · 1/16
名前あり⇄ 動画を替える ／ 9/3 レッスン後同上
解析中⇄ 動画を替える ／ 14:32（半透明のまま押せる）同上
右が空—上端は出さない。ペイン中央の ⊕「お手本を選ぶ」だけ（今のまま）
解析失敗⇄ 動画を替える ／ 14:32（失敗の表示はペイン中央）同上
  • タップ先は今と同じ。左は「動画」タブ、右は「お手本」タブで「動画を選ぶ」が開く
  • アイコンは arrow.triangle.2.circlepath（差し替えの意味。SF Symbols）。見出しは太字 11pt、添え字は 10pt の薄い色
  • 角丸は 12pt（2 行なのでカプセルより長方形寄り）。枠は白 40%（「フェーズ調整」と同じ）。タッチ領域は 44pt を保つ
  • VoiceOver のラベルは「動画を替える」、値に名前。E2E の識別子は pane.mine.swap / pane.model.swap に改める
  • 「自分」「お手本」の文言は上端から消える。「動画を選ぶ」の上部の「自分（左）に入ります」で側は伝わる
§3 決めてほしいこと

2 つ

一
A / B / C のどれにするか
推奨: C。動詞が先で、名前も残り、部品は増えない。名前が要らなければ A に落とせる（添え字を消すだけ）。
二
文言
推奨: 「動画を替える」。他の候補は「別の動画」「選び直す」。左右で同じ文言にする。
