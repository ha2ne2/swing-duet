ループ範囲をつまみで広げ縮めする

ループ範囲はメニューの「ダウンスイングのみ」などの 3 択で、境目はフェーズの位置に固定されている。 トップの少し前から、インパクトの少し後まで見たいときに手が無い。 区間を選んだらシークバーの両端につまみが出て、動画編集アプリ（CapCut）でカットの範囲を詰めるのと同じ動きでループの端を動かせるようにする。 端はコマ単位で動き、「トップ −3 コマ」のように読める。

§1 触れるデモ

メニューで区間を選ぶ → つまみをドラッグ

ループ範囲
実機では ↻ を押すと開く今のメニュー。項目は変えない。つまみを動かすとチェックは消え、↻ は「範囲あり」の表示のまま。
x0.30↻
アドレストップインパクトフィニッシュ

30fps の基準動画、1.85 秒の共通タイムライン（実秒）。つまみは最も近いフェーズから整数コマの位置にしか止まらず、ドラッグ中は再生ヘッドがその位置へ動いて映像でコマを確かめられる。 つまみ以外をドラッグすると今までどおりシーク。キーボードは ← → で 1 コマ。

§2 画面での見え方

4 つの状態

§3 置き場所の案

つまみをどこに出すか

案つまみの場所出るとき高さ評価
A シークバー・区間を選んだら 推し共通シークバーの両端の外側メニューで区間を選んだとき。全体・ループしないでは出ない+0操作の場所が増えない。区間を選ぶ → 少し広げる、の順で自然。既定の画面は今のまま
B シークバー・常に同上ループしない以外は常に（全体なら両端に）+0全体からも詰められる。既定の画面に白い棒が 2 本増え、端からのシークがつまみに取られる
C 別の帯シークバーの下に、選んだ区間だけを引き伸ばした帯区間を選んだとき+40ptコマの分解能は高い。縦画面でジョグホイールの下に収まらず、横画面は映像が消える
D 別画面メニューの「範囲を調整…」でシートを開く開いたとき+0再生を見ながら詰められない。フェーズ調整と似た画面がもう 1 枚増える
§4 決めてほしいこと

3 つ

一
A / B のどちらか
推奨: A。区間を選んだときだけ出す。「全体」の見た目は変えない。B は A の上に「全体でも出す」を足すだけなので、後から変えられる。
二
端の単位
推奨: 最も近いフェーズから整数コマ。読み出しが「トップ −3 コマ」になり、ジョグホイールと同じ物差しになる。秒の自由な位置は許さない。
三
ドラッグ中の映像
推奨: つまみの位置へシークして見せる。離したら、再生中だったなら範囲の先頭から再開。動画編集アプリの詰め方と同じで、端のコマを目で選べる。
