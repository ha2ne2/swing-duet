## 1. 画面

主要な画面は 3 つ。ホーム（スイングの一覧。起動画面）、動画を選ぶ（全画面のシート。「動画」「お手本」の 2 タブ）、ステージ（1 本のスイング vs お手本）。
選ぶ画面の中にプレビューと名前付けが入り、フェーズ調整は既存のまま。ホームとステージは NavigationStack のプッシュ。

| 画面 | 状態 | 内容 |
| --- | --- | --- |
| ホーム | 空 / 通常 / 解析中の行 / 選択モード | 大見出し「スイング」、右上「選択」、「★ ベスト」の節、日付ごとの節（撮影日時、新しい順）、下端に「＋ スイングを追加」。行 = スイング 1 本（インパクトのサムネイル、名前か時刻、テンポ比と最後に比べたお手本、☆、「…」）。フッター「★ 以外は 60 本まで残ります」 |
| 動画を選ぶ「動画」タブ | 許可 / 限定 / 拒否 → プレビュー | PhotoKit の自作グリッド。動画だけ、撮影日の新しい順、長さとスロー撮影の印。セルをタップ → プレビュー（再生、「この動画を使う」。右に入れるときは「お手本にする」→ 名前を付ける）。限定アクセスは許可した動画だけ ＋「さらに選ぶ」。拒否時は「設定を開く」と「写真アプリから選ぶ」（OS のピッカー） |
| 動画を選ぶ「お手本」タブ | 空 / 通常 | 「登録済み」（`role == .model`）と「★ ベスト」（★ のスイング）のカード。タップでそのまま使う（再解析なし）。カードの「…」（名前を変更 / 削除（確認あり）。★ ベストは「★ から外す」）。新しいお手本は「動画」タブから |
| ステージ | 通常 / 解析中 / お手本なし | ツールバーは ‹ スイング / タイトル（名前か日時）/ ☆ / 「…」（名前を付ける・削除）。左ラベル ⌄ → 「動画」タブ、右ラベル ⌄（無ければ ⊕）→ 「お手本」タブ。それ以外は現行の比較画面のまま |

## 2. 遷移

| いる画面 | 操作 | 行き先 | 起きること |
| --- | --- | --- | --- |
| ホーム | ＋ | 動画を選ぶ（「動画」タブ） | 左に入れる |
| 「動画」タブ | セル | プレビュー | 再生して確かめる |
| プレビュー（左） | この動画を使う | ステージ（左が解析中） | 原本を取り込み → 音声除去 → 解析。右は最後に比べたお手本（無ければ ⊕）。新しいスイングとして一覧に加わる |
| プレビュー（右） | お手本にする | 名前を付ける → ステージ（右が解析中） | 終わると「お手本」タブに並ぶ |
| 「お手本」タブ | カード | ステージ | 押した側にそのまま入る。右なら相手が更新され、右の位置合わせは自動フィットへ |
| 動画を選ぶ | タブ切り替え | 同じ | 入れる側は変わらない（上部に「自分（左）に入ります」） |
| ホーム | 行 | ステージ | 最後に比べた相手 → いつものお手本 → ⊕ の順で解決 |
| ホーム | ☆ / 「…」 / 選択 | 同じ / メニュー / 選択モード | ★ の付け外し / 名前・削除（即時 ＋ 元に戻す 6 秒）/ まとめて ★・削除 |
| ステージ | 左ラベル ⌄ | 「動画」タブ | 新しい動画なら新しいスイング（右は引き継ぐ） |
| ステージ | 右ラベル ⌄ / ⊕ | 「お手本」タブ | 右が差し替わる（再解析なし） |
| ステージ | フェーズ調整 | フェーズ調整 | 右はお手本そのもの（全スイングに効く） |
| ステージ | 「…」→ 削除 | ホーム | 元に戻す |
| どこでも | 再起動 | ホーム | 解析の続きがあれば再開 |

## 3. データ

```swift
enum ClipRole: String, Codable { case swing, model }

struct Clip: Codable, Identifiable, Equatable {
    var id: UUID
    var role: ClipRole
    var name: String              // 空なら日時
    var createdAt: Date
    var shotAt: Date?             // 撮影日時（PHAsset.creationDate）。一覧の並びと節
    var isFavorite: Bool          // スイングの ★（「お手本」タブにも並ぶ）
    var video: VideoConfig        // 現行のまま
    var analysis: AnalysisState   // queued / analyzing / done / failed(message)
    var pairing: Pairing?         // 最後に比べた相手と右ペインの位置合わせ
}
struct Pairing: Codable, Equatable { var partnerID: UUID; var scale = 1.0; var offsetX = 0.0; var offsetY = 0.0 }
struct Library: Codable { var clips: [Clip]; var reference: ReferenceSide }   // Documents/library.json
```

- いつものお手本は保存しない。`role == .swing` を新しい順に見て最初の `pairing.partnerID`（現行の `lastUsedModelID` と同じ考え）
- 上限：追加のたびに `role == .swing && !isFavorite && analysis == .done` を新しい順に 60 本残して削除（`swingLimit`）
- 削除は JSON から外すだけ。動画ファイルは次回起動時に参照の無いものを消す（現行）。元に戻すはメモリに持って戻す
- 取り込み：PhotoKit（`requestAVAsset`、`version = .original`）で原本を `Documents/Videos/` へ書き出し → 音声除去 → 解析。許可なしは現行の `PhotosPicker` 経路。同じ動画はサイズと長さで照合し、ファイルと解析結果を共有
- 旧データ：`models.json` → `Clip(.model)`、`projects.json` の各比較 → 左を `Clip(.swing, pairing: 右)`。右は `modelID` のお手本、無ければ `Clip(.model, name: "お手本 M/d HH:mm")`（同じ `fileName` があればそれ）。基準は最新の比較から

## 4. 実装の段階

1. モデルと保存（`Clip` / `Library` / `ClipStore`、移行、上限、元に戻す、解析キュー。単体テスト）
2. ホーム（`SwingListView`。ルートをこれに）
3. 動画を選ぶ（`VideoPickerSheet` を 2 タブに。「動画」タブ: PhotoKit の権限（許可 / 限定 / 拒否）、動画だけのグリッド、プレビュー、原本の書き出し。「お手本」タブ: 現行のカード ＋ ★ ベスト。`HistoryView` は削除）
4. ステージ（入力を「スイング 1 本 ＋ 相手」に。ツールバー、左右のラベルからタブ指定で選ぶ画面へ、解析中・お手本なし、保存先を pairing に）
5. E2E ハーネスと文書（SPEC §2.1 §2.5 §5、ARCHITECTURE §2、README、ROADMAP、TODO A を閉じる、build-test。E2E は権限ダイアログを押す手順が増える）

変わらないもの：`PlaybackController`、`SyncEngine`、解析、`PhaseEditView`、`VideoPaneView` の変換、`VideoThumbnail`。

## 5. 決めたこと（実装前に覆せる）

1. 動画は 1 本ずつ選ぶ。選んだらプレビュー → ステージ
2. ピッカーは自作し「動画」「お手本」の 2 タブ。押した側のペインに入る。写真ライブラリの権限を取り、原本を取り込む（TODO A）。拒否時は OS のピッカー
3. プレビューは「動画」タブの中。「お手本」タブのカードはプレビュー無し
4. ホームにお手本のチップは置かない。いつものお手本は最後に比べた相手
5. 起動は常にホーム
6. 左ペインもステージから選び直せる（新しい動画なら新しいスイング）。フィルムストリップは後から
7. スイングの削除は即時 ＋ 元に戻す。お手本の削除は確認
8. 同期の基準はアプリ全体で 1 つ。信頼度の低い検出は画面に出さない。スワイプは残すが案内しない
